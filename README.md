# Electrocoin.eu web

Statična web stranica (HTML/CSS/JS, bez build koraka) s dvije stranice: **O nama** i **Djelatnosti**.

## Objava na Cloudflare Pages

1. Cloudflare → Workers & Pages → Create → Pages → Connect to Git → odaberi ovaj repozitorij.
2. Framework preset: **None**, build command: prazno, build output directory: `/`.
3. Svaki push na `main` automatski objavljuje novu verziju; svaka grana dobiva vlastiti pregled.

## Lokalni pregled

Otvori `index.html` u pregledniku.
